# 演出實作規則

- 所有作品程式碼留在本目錄；只從 `xyz.js` 根入口匯入，且只允許 `src/scene/`、`src/audio/` 匯入。禁止私有路徑、修改引擎位元組。
- 時間軸、鏡頭、事件、亮度、混音曲線、種子與設計預算只改 `src/show/contract.ts`。不得改六段外緣；110 秒前星球拓樸完整。
- 不可新增執行期依賴，不用 `Math.random`、牆鐘計時器或網路驅動演出；沒有自由鏡頭。
- Node ≥22.13.0、pnpm 12.6.0。安裝前 `node scripts/verify-engine.mjs`，再 `pnpm install --frozen-lockfile`。
- 開發 `pnpm dev`；契約 `pnpm test`（node:test，不匯入引擎）；型別 `pnpm typecheck`；展出 `GAME_BASE=/last-two-minutes/ pnpm build`；預覽 `pnpm preview`。
- 視覺驗收依 PLAN.md Gate C，必須真的演完、暫停與重播，不能以純單元測試代替。音訊與畫面分別暫停；分頁隱藏不追幀。
- 禁止修改倉庫根 `CNAME`、`LICENSE`。本作品 AGPL-3.0；引擎及 vendor 授權原樣保存。

## 安全規則（企劃全文）

1. 正式環境只走 HTTPS。開發依小語最新裁示綁 `127.0.0.1` 並允許所有 Host；僅在可信環境使用。禁止 `file://`。WebGPU 與音訊解鎖本來就要求安全來源。
2. 執行期不載入遠端程式、遠端貼圖或遠端字型。引擎在建置期以核過雜湊的 tarball 進入 `vendor/`。
3. 雜湊門檻是 Release asset digest `sha256:353d97d6e8fe16346fc75db04e1263bcd774fef370425d6fe1c9fe80136db915`，並與發行 `SHA256SUMS` 一致。不一致即停止。禁止改門檻、禁止「先裝再補」。
4. GitHub Pages 不會套用倉庫裡的自訂 HTTP 標頭檔。starter 若只產出 header 檔，Pages 不會讓它變成回應標頭。CSP 必須以瀏覽器實際收得到的方式生效（頁內 meta，或已驗證會套用的邊緣規則）。做不到就在 Gate E 寫明未生效，不得勾成通過，也不得因此加入 `unsafe-eval` 或遠端 script。本機 Vite 開發伺服器不是正式 CSP 的豁免理由。
5. 沒有帳號、權杖、Cookie 會話或可上傳內容。日誌不得新增這類欄位。
6. 觀眾輸入只有開始、暫停、繼續、重播、無聲。不讀 query 來載入任意場景或任意 URL。
7. 播放開始後不得發出網路請求。缺檔在開始前失敗，不在演出中途補抓。
8. 程式產生的貼圖邊長 ≤ 2048，且不得超過引擎單張上限（邊長 8192、像素 4,194,304）。超限拒絕，不縮小後靜默繼續。
9. 執行期依賴只有釘選的 `xyz.js`。不加入未在本企劃書出現的執行期套件。升級引擎版本是另一次裁示，不是實作時順便換 tag。
10. 圖形能力不足時拒絕演出，不降級成另一種視覺作品。音訊解鎖失敗時不得假稱已有聲；可改走明示的「無聲播放」，時鐘規則不變。
11. 不啟用會快取任意缺檔的離線策略。v1 不宣稱可離線安裝。
12. 倉庫根 `LICENSE` 維持 AGPL-3.0，不改授權標頭，不另放一份宣稱整包為 Apache-2.0 的 `LICENSE`。引擎套件內的 Apache-2.0 與 vendor 音訊授權原樣保留在複製進去的引擎檔裡。
