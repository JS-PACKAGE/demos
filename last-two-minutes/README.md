# 一顆星球最後的兩分鐘

以 **XYZ.js 1.13.0** 即時渲染的 120 秒瀏覽器演出，不是預錄影片。星球、城市燈光、艦隊、地殼碎塊、GPU 粒子與原創 OPM／PCM 聲音全部由程式產生；無遠端美術、音樂、帳號或分析服務。

**目前為審閱階段，尚未發布。** 主入口已整合完整 120 秒演出，使用與預覽相同的新星球、主力艦、戰鬥與崩解美術；仍待小語審閱美術與聲音，也尚未完成最終 Gate C／E。

## 本機

需要 Node.js ≥22.13.0、pnpm **12.6.0**。若本機沒有 pnpm，可把以下 `pnpm` 替換為 `npx --yes pnpm@12.6.0`。

```sh
cd last-two-minutes
node scripts/verify-engine.mjs
pnpm install --frozen-lockfile
pnpm dev
```

開發伺服器依小語最新更正綁 `127.0.0.1`，保留 `allowedHosts: true`，接受任何 Host；本機開 `http://127.0.0.1:5173/`。不直接對其他網路介面監聽。允許所有 Host 會取消 hostname／DNS-rebinding 防護，僅在可信環境使用，不是正式部署。禁止 `file://`；WebGPU／音訊仍受瀏覽器安全來源限制，非 loopback 網域請用 HTTPS。需要 **WebGPU 或支援 3D／instancing 的 WebGL2**；Canvas2D 只顯示不支援，不會以 2D 替代。缺少浮點色彩附件時關閉 HDR/bloom／加權透明。

按「開始演出」以使用者手勢解鎖官方八槽音訊；解鎖與解碼完成前不推進時間。也可明示「無聲播放」。演出中只提供暫停、繼續、重播；重播在同頁重置時間、種子、粒子與音訊，不重新載入。隱藏分頁時時間與聲音停止、不追幀。演完 120 模擬秒後停住、不循環。含閃光效果。

新模型使用連續位移地形與 PBR 貼圖、分層金屬艦體、不規則厚曲面殼與破裂內側。144 段裂縫以 12 批 vertex-alpha mask 漸進顯露，而非 144 次獨立繪製。崩解後鏡頭拉遠、碎塊餘熱消退，最後不保留完整星球。GPU 粒子在重播時重新建立並 prepare：官方 `clear()` 不重置完整 native 時鐘與隨機序列。

## 完整時間軸

| 模擬秒 | 演出 |
|---|---|
| 0–20 | 星球全幅，鏡頭拉開；主力艦低空掠過，12 秒起兩方艦隊從畫面兩側滑入 |
| 20–50 | 艦隊交火，各砲塔獨立瞄準，35 秒一艘護衛艦被擊毀；星球留在畫面內 |
| 50–70 | 硬切貼地仰望：天空小規模交火、巨艦掠過頭頂 |
| 70–95 | 主武器充能、防守艦被擊毀（77、91 秒）與安靜星球鏡頭交替硬切；95 秒光束命中 |
| 95–110 | 灼點、裂縫與內光；完整輪廓與近乎無聲的停頓 |
| 110–120 | 地殼外翻、核心、衝擊波，艦艇被推離，最後降亮停在塵雲、碎片與一道光 |

## 原創 OPM 配樂

八種原創四運算子 FM 音色：弦樂、號角、低音、短弓 ostinato、定音鼓、軍鼓、豎琴、警報。468 個編排音符包含八音主題、開場和聲、120-BPM 戰鬥節奏、地表回應、倒數加速與命中後留白；不是採樣交響樂，也不是另一套 synth。

使用官方八槽 OPM、每音符音色力度與空間定位，加入原創 impulse 的原生 convolution reverb、高通與各 context 的 compressor；不宣稱跨八個 context 的全域 limiter。四段原創 seeded PCM 音效仍由程式產生。力度在官方 voice validation **之前**編寫，保留驗證回傳的 voice 本體，避免複製正規化 voice 後失去 adapter 的版本識別而無法播放。

- `src/show/contract.ts`：時間、鏡頭、事件、亮度、增益、種子與設計預算的唯一真值；`EVENTS` 只留導演刻意對齊的標記。

- WebGPU 實際播放整個 120 秒（整合階段首次量測）：時間到 120.00 後停在結尾；7,203 個 RAF 樣本無頁面或引擎錯誤，幀間隔 p50 16.7 ms、各 10 秒段 p95 17.3–17.5 ms，只有第一幀 214 ms（初次提交）。RAF 間隔受顯示器 vsync 限制，不代表 GPU 餘裕；沒有取得 GPU timestamp。寫實化之後的量測見下一節。
- 逐段停格檢查 0–120 秒：hero 艦掠過、艦隊滑入、交火、擊毀、地表、主武器充能、兩次防守艦擊毀、光束命中、傷口、崩解、衝擊波與餘燼均有畫面。
- 正式 `/last-two-minutes/` 建置與 strict CSP 伺服器下含聲音播放至 41 模擬秒：88 個原生 PCM 來源，其中 85 個與預期 cue 時間相差 ≤120 ms（中位數 14 ms，最大 233 ms）；預期但未觀測到的 4 個 cue 位於 21.6–22.7 秒的密集連發，推論是 PCM 同時最多兩個來源的上限所致。無頁面或引擎錯誤。這不是喇叭聽感或 sample-accurate 同步驗收。
- 整合階段的已知限制（地表網格折面、天空全黑、少量大型艦）已由下一節的寫實化處理，其餘仍待驗證項目見該節末。

### 寫實化（小語要求「盡可能逼真」）

先更正一項先前的錯誤判斷：引擎並非只有貼圖＋顏色的材質。它有 PBR（metallic／roughness／normal／occlusion／emissive）、NativeMaterial3D 自訂 shader、EnvironmentMap、級聯陰影、霧與後處理，這一輪就是靠這些做的。

- **星球**：雲層改成連貫的氣旋與雲帶（不再是黑洞斑點）、雲影烘進地表；整體地形起伏降到十分之一，輪廓是平滑球體；植被與雪線色彩重調。雲與大氣殼由 256×128 降至 128×64（輪廓偏差 < 0.25 px），省下約 98k 三角形。
- **地表鏡頭**：新增 `ground.ts`——局部高解析曲面地形（384×256）、高度／坡度驅動的岩石與雪貼圖、獨立細節法線與 720 顆 seeded 岩石 instance，鏡頭高度取樣同一份高度場。新增 `sky.ts`：隨高度淡出的 Rayleigh／Mie 天空（天頂深藍→地平線淡色、日盤與暈）與大氣霧；地表看到的不再是黑天。
- **艦體**：整條船長的非重複 PBR 圖集（接縫、鉚釘、檢修蓋、汙痕、尾部焦痕）、停泊環、RCS 噴嘴、天線、航行燈與凹入式引擎光環；capital／cruiser／frigate 三種輪廓（`createShipModel(hullClass)`）。尾流改為窄的巢狀錐殼，不再是旗狀色塊。開場 1–9 秒鏡頭追著 hero 艦（約佔畫面寬 40%）再拉遠揭示星球與艦隊。
- **主武器**：圓角壓力容器、倒角裝甲蓋、面板／螺栓／焊縫貼圖與鏽痕、維修棧橋與扶手、停靠的小艇、分段線圈環、含聚焦環的凹入砲口；放電為錐形多層殼加五條螺旋電弧（約 +13 meshes／+121k 三角形）。
- **艦隊交火**：20–50、50–70、70–95 秒各加入 56／42／48 艘護衛，用五列梯隊與三批 InstancedMesh，遠處為刀鋒形艦體與引擎光點（不再是飛碟狀圓盤）；砲口閃光、有限速度曳光彈、點防禦攔截、六角護盾漣漪、命中處 Decal 焦痕，擊毀時為五塊大型旋轉艦體斷片加熔渣。
- **崩解**：沿法線噴出的傷口噴流、冷卻中的熔岩殼、288 顆旋轉不規則岩塊、薄而帶亂流的壓縮前鋒與 6 層低不透明度塵殼；崩解後熱度從黃白經橘紅冷卻到暗灰，結尾仍留餘燼。95–110 秒鏡頭拉近至星球約佔畫面 80% 高。星球碎塊內側有熔岩層理與發光斷面。
- **效能**：初版寫實化在 95–106 秒（星球佔滿畫面、傷口與噴流）每 8–12 幀掉一幀 33 ms。以 3200×1800 放大差異逐項隔離，主要成本是撞擊時 210 個陰影 caster、全螢幕雲與大氣殼的三角形，以及預設 BLEND 的不透明材質；已把背景護衛的陰影 caster 在 95 秒後關閉、塵殼 12→6、雲與大氣殼降採樣、不透明表面明確設為 OPAQUE。
- 最終整合在正式 `/last-two-minutes/` 建置與 strict CSP 下按「開始演出」播放完整 120 秒：7,561 個 RAF 樣本只有 1 個 >25 ms（第一幀），各 10 秒段 p95 16.7–16.8 ms（含 95–110 秒），時間停在 02:00，無頁面或引擎錯誤。這次沒有統計原生 PCM 來源；仍是 vsync 限制的 RAF 間隔，不是 GPU timestamp，不宣稱 60fps 認證。
- **審閱階段發現的問題**：第一輪後星球雲層呈斑點、輪廓有鋸齒、地表鏡頭是無特徵的平坦灰原——這些是由整合後的畫面逐段檢視發現並重做的，不是一次到位。
- **仍然不是照片級**：雲仍是薄殼近似（無體積散射）；地表前景相對平滑、遠景可信；艦隊遠景細節簡化；碎塊外表面仍是偏大的風格化平面；擊毀碎裂為預製幾何，不是物理模擬。尚未驗證 WebGL2 新美術與 shader（皆提供 GLSL）、實體 Safari／手機、喇叭聽感、輔助科技與最終 Gate C／E；寫實化之後的音訊 cue 時序也沒有重新量測（41 秒的量測是整合階段做的，艦隊加入護衛不改變 cue 腳本）。

### 電影感（小語要求「更電影風格感」）

- **鏡頭**（`src/scene/cinema.ts`，純函式，只依絕對時間，拖曳／倒帶／重播得到同一畫面）：每個鏡頭沿自己的視線退後 1.2–1.3 倍並同比例收窄視角（長焦壓縮：星球疊在艦隊後方，被攝體平面的取景不變）；地表鏡頭站在地面，改為裁切 FOV ×0.8，不移動眼睛。靜態鏡頭加入 8–12% 的緩推；手持微晃（0.05–0.2°，地表與傷口階段較大）、命中事件的衰減震動（開火 0.22°、擊毀 0.12°、95 秒命中 1.15°、110 秒崩解 1.9°、112 秒衝擊波 1.5°），以及 95–110 秒隨時間增強的隆隆震動與輕微 roll。
- **片感疊層**（`src/ui/film.ts` + `style.css`，由瀏覽器合成器疊在 canvas 上）：2:1 寬銀幕黑邊（16:9 畫面上下各 5.56%）、暗角、逐幕色偏（soft-light：開場冷藍、交火暖橘、地表鋼藍且降飽和、倒數琥珀、傷口熔爐橘、崩解後褪色）、canvas 對比與飽和度，以及 24 fps 的 seeded 顆粒。各幕結尾 2.5 秒平滑過渡到下一幕。
- **為什麼不用引擎的全螢幕後處理**：我先做了 `effects3D` 原生 WGSL／GLSL 一遍式膠片 shader（色差、橫向變形鏡頭光條、紅暈、分色調色、暗角、顆粒），並試了 SSAO 與景深。正式建置完整播放時 80–120 秒每 10 秒有 31–64 個 >25 ms 幀。隔離後發現即使是什麼都不做的 `return color;` 效果，開啟 `effects3D` 也使引擎回報的 GPU 時間增加約 20–32（單位與 vsync 間隔不一致，只作相對比較；場景越重增加越多）；開啟 SSAO 或景深則再增加。所以最後移除 shader、SSAO、景深，改走 CSS 合成器。代價：沒有色差、光條、紅暈與景深。
- **在鏡頭審閱時發現的既有問題**：66 秒地表鏡頭有一塊巨大的白色岩石幾乎貼在眼前（種子岩石剛好落在鏡頭位置，近距離填滿畫面）。`ground.ts` 現在沿地表鏡頭路徑取 11 個眼睛位置，凡是離眼睛距離小於「岩石半徑 ×1.4 + 0.04」的岩石一律收縮為不可見（保留其餘種子配置）。`planetRotation` 因此從 `show-scene.ts` 移到 `CONTRACT.visual`。
- 新增 4 個測試（`tests/cinema.test.ts`）：整段時間鏡頭有限且可重現、地表眼睛不動、長焦壓縮保持被攝體取景、調色有界且各幕過渡平滑；共 30 個測試通過，型別檢查與正式建置通過。
- **效能（正式建置、strict CSP、按「開始演出」完整 120 秒）**：7,547 個 RAF 樣本，15 個 >25 ms（0.2%，90–100 秒段 6 個、110–120 秒段 9 個），其餘各 10 秒段 p95 皆為 16.7–16.8 ms，無頁面或引擎錯誤。仍是 vsync 限制的 RAF 間隔，不是 GPU timestamp；不宣稱 60fps 認證。
- **未驗證**：WebGL2、Safari／Firefox 的 `mix-blend-mode` 疊在 WebGPU canvas 上的表現、實體裝置與手機、`prefers-reduced-motion`（只停顆粒位移，已實作但未實測）。2:1 黑邊裁掉上下各 5.56%，崩解階段星球約佔畫面 80% 高仍在可視範圍，但碎塊飛出時會被黑邊裁切。
